- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

## Important

Black Folder is designed as a local-first document wallet.

The application may use third-party services including:

- Google Mobile Ads (AdMob)
- Google User Messaging Platform (UMP)
- Google Play Billing

This policy should be reviewed whenever the application's data practices,
advertising configuration, billing configuration, or backend services change.
